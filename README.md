# 📊 Jornada do Cliente - Análise de Engajamento, Conversão e Retenção

## 📌 Sobre o Projeto
Este projeto consiste no desenvolvimento de um dashboard estratégico no Power BI com foco na análise completa da jornada do cliente, desde a aquisição até a retenção.

O objetivo é fornecer uma visão integrada do comportamento dos clientes, permitindo identificar oportunidades de crescimento, gargalos operacionais e riscos financeiros.

---

## 🎯 Objetivo do Projeto
Apoiar a tomada de decisão através de dados, permitindo:

- Identificar oportunidades de crescimento
- Mapear gargalos na jornada do cliente
- Monitorar inadimplência e riscos financeiros
- Avaliar performance comercial
- Melhorar retenção de clientes

---

## 🧠 Etapas da Jornada Analisadas
- Aquisição  
- Instalação  
- Ativação  
- Uso contínuo  
- Receita e inadimplência  
- Retenção  
- Cancelamento  

---

## 📊 Principais Indicadores (KPIs)

### 📍 Performance de Aquisição
- Total de Clientes Ativos  
- Tempo Médio de Instalação  
- Receita de Clientes Ativos  
- Ticket Médio  
- Situação de Contratos  

### 💰 Otimização da Receita
- Receita Total  
- Clientes Inadimplentes  
- % de Ativos Problemáticos  
- Mensuração de Perdas  
- Faturamento vs Inadimplência  

---

## 📈 Insights Gerados
- Identificação de regiões com maior concentração de clientes  
- Análise de crescimento mensal (MoM)  
- Identificação de vendedores com maior performance  
- Detecção de perda de receita por inadimplência  
- Comparação entre vendas, cancelamentos e pagamentos  

---

## 🛠️ Ferramentas Utilizadas
- Power BI  
- Power Query (ETL)  
- Excel  
- Modelagem de Dados (Star Schema)  

---

## 🗂️ Fontes de Dados
- Dados de clientes, contratos e pacotes  
- Dados financeiros (faturamento e recebimentos)
